# React Portfolio & Demo Page

A React-based portfolio website featuring interactive frontend demos built with the PokéAPI.

🌐 **Live Site**: [https://kevinttran.github.io/](https://kevinttran.github.io/)

## Overview

This project showcases modern React development practices and includes two featured interactive demos:

### Featured Demos

- **Pokédex App** - A full-featured Pokédex with infinite scroll, type filtering, search by ID, and detailed Pokémon information
- **Type Match-Up Visualizer** - An interactive tool to calculate type effectiveness and view the complete type matchup matrix

Both demos leverage the [PokéAPI](https://pokeapi.co/) for real-time data fetching.

## Tech Stack

- **React 19** - Core framework
- **React Router** - Client-side routing with HashRouter for GitHub Pages compatibility
- **TanStack Query (React Query)** - Data fetching, caching, and infinite queries
- **Framer Motion** - Smooth animations and transitions
- **React Icons** - Icon library
- **React Markdown** - Blog post rendering
- **Service Worker** - Offline caching for demo apps

## Development

### Installation

```bash
npm install
```

### Running Locally

```bash
npm start
```

Open [http://localhost:3000](http://localhost:3000) to view in your browser.

### Build for Production

```bash
npm run build
```

### Deploy to GitHub Pages

```bash
npm run deploy
```
